# drahtseilakt-toolbox

[English](README.md) · **Русский** · [Deutsch](README.de.md) · [简体中文](README.zh.md)

Готовит уровни для [Drahtseilakt](https://github.com/eugene-vereshchagin/drahtseilakt), нового движка Ballance, на
машине игрока и из его собственной копии игры. Игра только играет то, что лежит в её папках уровней; всё тяжёлое,
что делает уровни современными, живёт здесь, и игре ничего из этого не нужно.

```
drahtseilakt-toolbox remaster [--scale N] [--model NAME] [--data DIR]
```

`remaster` переводит оригинальные уровни из копии в `levels/remastered/` игры (открытый формат), даёт каждому
уровню более круглые формы (записываются в уровень рядом с исходными мешами, физика по-прежнему берёт исходные, так
что прохождения те же) и увеличивает текстуры в N раз (по умолчанию 4; 1 — не трогать). С Real-ESRGAN текстуры
получают детали, без него увеличиваются фильтром Lanczos (как и текстуры меньше 64 пикселей: на них он выдумывает
детали). Real-ESRGAN ищется в `realesrgan/` рядом с программой
toolbox, затем в PATH; используемая версия закреплена в [third-party.txt](third-party.txt). Оригиналы сохраняются
в `textures.original/`. Общие для всех уровней части (шары, модули, трансформер) переделываются так же в скрытую
`levels/remastered/.shared/`, и в ремастер-уровнях игра рисует их такими. Оригинальные уровни при каждом запуске
строятся заново из копии. Повторяющаяся плиткой текстура увеличивается вместе с полосой своего противоположного края, поэтому на стыках плиток
нет швов. `--model` выбирает другую модель Real-ESRGAN, положенную в его папку `models/` (по умолчанию —
realesrgan-x4plus, она идёт в комплекте). После обновления toolbox запустите снова — уровни обновятся.

Toolbox никогда не выходит в сеть и не трогает оригинальную копию игрока.

## Сборка

Чтение уровней у toolbox общее с игрой: нужен клон репозитория игры рядом, в `../ballance/drahtseilakt`. Затем
`cargo build --release --offline`. Для Real-ESRGAN распакуйте закреплённый архив в `third_party/realesrgan/` и
сделайте ссылку `target/release/realesrgan` на эту папку.

GPL-3.0-only, как и игра.
